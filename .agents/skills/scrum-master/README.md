# Scrum Master skill for this workspace

This Codex skill keeps the Neuron Mesh and Agent planning records independent. It is included in the repository so a trusted clone can use the same process guidance without installing a global skill on each computer.

Read SKILL.md for the operating rules. Its templates and initializer are intentionally limited to the two product planning paths in this repository. It does not require a tracker, companion skill, fixed sprint duration, estimation system, or team ceremony.

The skill is adapted from [tronghieu/agent-skills](https://github.com/tronghieu/agent-skills/tree/main/skills/scrum-master). See UPSTREAM.md and LICENSE for attribution and terms.

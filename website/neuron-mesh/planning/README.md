# Scrum de Neuron Mesh

Esta carpeta es la única fuente de Scrum para la web Neuron Mesh. Contiene el backlog, el incremento actual, el historial de versiones y los cierres de iteración. El Scrum de Agent vive en `../../.. /websites/agent/planning/` desde la raíz del repositorio; no se mezclan sus objetivos ni sus estados.

## Alcance

Incluye el mantenimiento de la web clásica, sus rutas y contenido actuales, y las garantías de instalación, selección y publicación que la mantienen disponible en GitHub Pages. El selector de publicación y su workflow se registran aquí porque protegen la web hoy publicada.

## Fuentes de verdad

1. `SPRINT_ACTUAL.md`: trabajo activo y verificaciones pendientes.
2. `BACKLOG.md`: trabajo potencial, sin compromiso hasta que se seleccione.
3. `VERSIONES.md`: versiones y estado de validación o publicación.
4. `sprints/`: registros de ciclos cerrados.
5. `HISTORIAL.md`: resumen saneado de versiones y decisiones heredadas.

## Acuerdo de trabajo

- Juan es Product Owner y decide prioridad, alcance, copy y aceptación.
- Cada sprint se orienta a un incremento revisable; no tiene duración artificial.
- No se usan estimaciones, velocity, burndown ni métricas de equipo sin datos y una necesidad real.
- Se distingue implementación local, comprobación local, ejecución remota de Actions y publicación.
- Los cambios editoriales preservan el inglés y el español y no añaden afirmaciones sin evidencia.
- Las fuentes privadas importadas no se copian aquí ni a la web.

## Definición de terminado

La salida acordada existe, las comprobaciones proporcionales tienen resultado registrado, el backlog y la versión reflejan lo ocurrido y los límites restantes son explícitos. Un build local no demuestra que el workflow remoto haya terminado ni que GitHub Pages haya publicado.

# Contexto público curado

Esta carpeta contiene referencias breves y aptas para versionar que ayudan a trabajar en el portfolio. No es el perfil final ni forma parte de ninguna aplicación publicada: GitHub Pages recibe exclusivamente el `dist/` de la web seleccionada.

## Fuentes

- `public-profile-snapshot.md`: resumen del copy que ya era público en Neuron Mesh y de lo que debe volver a verificarse antes de reutilizarlo.
- El contenido público canónico actual de Neuron Mesh está en `website/neuron-mesh/src/data/site.ts` y en sus páginas Astro.
- Las decisiones y los requisitos futuros de la interfaz Agent pertenecen a `websites/agent/planning/`, no a esta carpeta.

## Privacidad y uso

Se excluyeron el CV, notas privadas, material importado sin revisar, credenciales y datos de contacto duplicados. No copiar archivos de `contexto/` a este directorio ni a una web. Confirmar con Juan cualquier fecha o estado profesional antes de presentarlo como actual.

# Agent portfolio

Aplicación Astro independiente para la variante del portfolio con interfaz de editor. En esta primera fase solo existe un scaffold compilable; no contiene aún la interfaz ni el perfil final.

Desde la raíz del repositorio:

```sh
npm run install:agent
npm run dev:agent
npm run build:agent
```

El encargo, backlog, sprint y versiones propios están en `planning/`. La web activa de GitHub Pages se selecciona en `../../site.config.json`.

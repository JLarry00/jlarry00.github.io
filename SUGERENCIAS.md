# Sugerencias

Añade aquí ideas para Neuron Mesh o Agent. Esta es una bandeja de entrada temporal: Codex revisa cada propuesta y la incorpora al `BACKLOG.md` del producto adecuado como una o varias tareas, o la integra en una tarea que ya exista.

```md
### Título breve
- Producto: Neuron Mesh / Agent / Ambos / Por determinar
- Sugerencia: qué te gustaría conseguir
- Motivo o resultado esperado: para quién o por qué importa
- Prioridad deseada (opcional): P0 / P1 / P2 / P3 / Por decidir
- Notas o límites: opcional
```

Codex revisará las entradas al comenzar trabajo en este workspace. Si falta un dato que pueda cambiar el producto, el alcance, la aceptación, la evidencia o la prioridad, te preguntará antes de registrar la propuesta. Las entradas pendientes de respuesta se quedan aquí. Una vez reflejada en el backlog correspondiente —o si decides que no se llevará adelante— se elimina de esta bandeja; desde entonces el backlog es su fuente de verdad y la tarea sigue el proceso normal.

Si una propuesta abarca las dos webs, se registran resultados separados en sus respectivos Scrums. No se crea un backlog compartido. No incluyas secretos, CVs ni información personal privada en este archivo.

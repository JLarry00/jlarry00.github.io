# Start or resume one product Scrum

1. Determine whether the work belongs to Neuron Mesh or Agent from the requested outcome and the root workspace rules.
2. Read only that product's planning README, current sprint, relevant backlog entries, and latest closed increment.
3. Report the goal, recorded state, and open decisions from those files. Do not infer elapsed sprint time, capacity, or progress percentages.
4. If the planning directory is missing, use scripts/init-scrum.sh with exactly one product name. The script creates only missing files at that product's path.
5. If the user supplied a plan or scope, reflect it in the selected product's records. Do not ask for information already recorded, and do not claim acceptance that Juan has not given.

There is no shared tracker contract in this workspace. GitHub, local builds, and other tools are evidence only when actually checked. Never invent a connection or fetch result.
